# XUXU

Aaron's DAW, built for recording.

## Download

Get the one for your computer. You install it once and it updates itself from then on.

### Windows

**[Download XUXU 0.3.14 for Windows](https://github.com/aarontrooperprod/xuxu-actualizaciones/raw/main/XUXU.zip)** (Windows 10 and 11, 64-bit, 4.4 MB)

1. Unzip it into a folder of yours (for example `Documents\XUXU`), not in Program Files.
2. Open `XUXU.exe`. If Windows says "Windows protected your PC", click **More info** and then **Run anyway**.
3. From then on XUXU updates itself: when you open it, it tells you if there's a new version and asks. There's also **Options → Check for Updates…**.

## What's new in 0.3.14

## XUXU 0.3.14 🛟
**Vovious and Melodyne**
- **Splitting a clip no longer wipes your Vovious or Melodyne edits.** Before, each piece started from scratch and the edits could vanish when you reopened the project. Thanks, Gabriel.

**Your work is safer**
- Every time you save, the previous version goes to a **Backup** folder inside the project (the last 10), like Ableton.
- "Don't Save", "Keep the saved one" and "Discard" no longer delete the autosave: it's set aside, so you can get it back.

**Other**
- The start screen has an **Open…** button.
- Skins: the factory ones are **XUXU** and **TROOPER3**; your own skins have a visible ✕ to delete them.
- The empty channel column on the left hides when no track is selected.
