# XUXU

Aaron's DAW, built for recording.

## Download

Get the one for your computer. You install it once and it updates itself from then on.

### Windows

**[Download XUXU 0.3.32 for Windows](https://github.com/aarontrooperprod/xuxu-actualizaciones/raw/main/XUXU.zip)** (Windows 10 and 11, 64-bit, 4.8 MB)

1. Unzip it into a folder of yours (for example `Documents\XUXU`), not in Program Files.
2. Open `XUXU.exe`. If Windows says "Windows protected your PC", click **More info** and then **Run anyway**.
3. From then on XUXU updates itself: when you open it, it tells you if there's a new version and asks. There's also **Options → Check for Updates…**.

## What's new in 0.3.32

## XUXU 0.3.32 🎛️
**Mixer**
- Inserts and Sends now line up on every strip, always. Each has its own box, and only the one with more than fits scrolls.
- Sends fold with their arrow, like In/Out and Inserts.
- Once a track sends to a bus, that bus shows on every track at −∞, like Live's return tracks. Drag its level to start the send (double-click = 0 dB).

**Library**
- It remembers its width. The first time, it opens just wide enough.
- An × in the search box clears it.
