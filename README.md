# XUXU

Aaron's DAW, built for recording.

## Download

Get the one for your computer. You install it once and it updates itself from then on.

### Windows

**[Download XUXU 0.3.25 for Windows](https://github.com/aarontrooperprod/xuxu-actualizaciones/raw/main/XUXU.zip)** (Windows 10 and 11, 64-bit, 4.7 MB)

1. Unzip it into a folder of yours (for example `Documents\XUXU`), not in Program Files.
2. Open `XUXU.exe`. If Windows says "Windows protected your PC", click **More info** and then **Run anyway**.
3. From then on XUXU updates itself: when you open it, it tells you if there's a new version and asks. There's also **Options → Check for Updates…**.

## Español

El DAW de Aaron, para grabar. Baja el de tu computadora: se instala una vez y de ahí se actualiza solo.

### Windows

**[Bajar XUXU 0.3.25 para Windows](https://github.com/aarontrooperprod/xuxu-actualizaciones/raw/main/XUXU.zip)** (Windows 10 y 11 de 64 bits, 4.7 MB)

1. Descomprime el zip en una carpeta tuya (por ejemplo `Documentos\XUXU`), no en Archivos de programa.
2. Abre `XUXU.exe`. Si Windows dice «Windows protegió tu PC», picas **Más información** y luego **Ejecutar de todas formas**.
3. De aquí en adelante XUXU se actualiza solo: al abrir te avisa si hay versión nueva y te pregunta. También está **Opciones → Buscar actualizaciones…**.
