# XUXU

Aaron's DAW, built for recording.

## Download

Get the one for your computer. You install it once and it updates itself from then on.

### Windows

**[Download XUXU 0.3.22 for Windows](https://github.com/aarontrooperprod/xuxu-actualizaciones/raw/main/XUXU.zip)** (Windows 10 and 11, 64-bit, 4.6 MB)

1. Unzip it into a folder of yours (for example `Documents\XUXU`), not in Program Files.
2. Open `XUXU.exe`. If Windows says "Windows protected your PC", click **More info** and then **Run anyway**.
3. From then on XUXU updates itself: when you open it, it tells you if there's a new version and asks. There's also **Options → Check for Updates…**.

## What's new in 0.3.22

## XUXU 0.3.22 🔀
**Plug-in sidechain, like in Live and Logic**
- Compressors, gates and anything with a sidechain input can now listen to another track.
- Open the plug-in: the **Sidechain** bar on top picks the track and where it listens (Pre FX, Post FX or Post Mixer).
- Right-click the plug-in in Inserts → **Sidechain…** for Gain, Mix and Mute too.
- A little arrow on the insert tells you it has a sidechain.
- Every change undoes with Ctrl+Z and is saved with the project.
