# XUXU

Aaron's DAW, built for recording.

## Download

Get the one for your computer. You install it once and it updates itself from then on.

### Windows

**[Download XUXU 0.3.15 for Windows](https://github.com/aarontrooperprod/xuxu-actualizaciones/raw/main/XUXU.zip)** (Windows 10 and 11, 64-bit, 4.5 MB)

1. Unzip it into a folder of yours (for example `Documents\XUXU`), not in Program Files.
2. Open `XUXU.exe`. If Windows says "Windows protected your PC", click **More info** and then **Run anyway**.
3. From then on XUXU updates itself: when you open it, it tells you if there's a new version and asks. There's also **Options → Check for Updates…**.

## What's new in 0.3.15

## XUXU 0.3.15 ❄️
**Freeze and Bounce, like Ableton**
- **Freeze Track** (Ctrl+Alt+Shift+F): the track plays its rendered audio and its plugins go to sleep, so they use no CPU or memory. Fader, pan and sends still work. Unfreeze and the plugins come back exactly as they were.
- **Freeze Group**: something Ableton can't do. Nothing inside the group runs; the group plays its render.
- **Bounce Track in Place**: the track becomes audio, with the reverb tail in its own clip.
- **Bounce to New Track** (Ctrl+B): bounce a selection, some clips or the whole track (from its header) to a new track below. The originals get switched off, like pressing 0.
- **Bounce Group in Place / to New Track**, and **Paste Bounced Audio** (Ctrl+Alt+V): copy, then paste it as it sounds right now.

**Tracks**
- New audio tracks start with monitoring **off**. Turn it on with the "I" button.
- Tag and Icon in the track menu are now submenus, so the menu fits on screen.

**Files**
- Every file and folder XUXU makes is now in English, whatever language XUXU is in: project.json, Takes, Templates, Recovery… Your old folders and projects move over by themselves.
- Heads up: once you save a project with this version, older versions of XUXU can't open it. If you share projects, update first.
