# XUXU

Aaron's DAW, built for recording.

## Download

Get the one for your computer. You install it once and it updates itself from then on.

### Windows

**[Download XUXU 0.3.27 for Windows](https://github.com/aarontrooperprod/xuxu-actualizaciones/raw/main/XUXU.zip)** (Windows 10 and 11, 64-bit, 4.7 MB)

1. Unzip it into a folder of yours (for example `Documents\XUXU`), not in Program Files.
2. Open `XUXU.exe`. If Windows says "Windows protected your PC", click **More info** and then **Run anyway**.
3. From then on XUXU updates itself: when you open it, it tells you if there's a new version and asks. There's also **Options → Check for Updates…**.

## What's new in 0.3.27

## XUXU 0.3.27 📁
**A real project file**
- A project is now a folder with **Name.xuxu** inside, with the XUXU logo. **Double-click it** and XUXU opens right into that project (if XUXU is already open, it opens there).
- **Save As** asks for the name and creates its folder. **Open** picks the .xuxu file.
- Older projects still open. When you save them, they get their .xuxu file.

**Much smaller projects**
- Heavy plug-in data (VocAlign, Melodyne, Vovious…) is now saved apart, compressed, and only once. A project with lots of VocAlign went from 427 MB to under 1 MB, plus 41 MB of plug-in data.
- Backups no longer copy hundreds of MB on every save. The first save keeps one last big backup, just in case.
- Open your project and save it once to shrink it.
