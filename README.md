# XUXU

Aaron's DAW, built for recording.

## Download

Get the one for your computer. You install it once and it updates itself from then on.

### Windows

**[Download XUXU 0.3.19 for Windows](https://github.com/aarontrooperprod/xuxu-actualizaciones/raw/main/XUXU.zip)** (Windows 10 and 11, 64-bit, 4.6 MB)

1. Unzip it into a folder of yours (for example `Documents\XUXU`), not in Program Files.
2. Open `XUXU.exe`. If Windows says "Windows protected your PC", click **More info** and then **Run anyway**.
3. From then on XUXU updates itself: when you open it, it tells you if there's a new version and asks. There's also **Options → Check for Updates…**.

## What's new in 0.3.19

## XUXU 0.3.19 🎯
**Selecting like Ableton Live** (measured in Live itself)
- Click a track's lane and that track gets selected.
- Up / Down arrows move between tracks. Shift + Up / Down adds tracks. Ctrl + Up / Down moves the selected tracks.
- Dragging a time selection across tracks selects only the track where you let go, like Live.
- **Shift + click** moves the nearest edge of the selection to that spot (in time and tracks). **Shift + drag** grabs that edge.
- **Ctrl + click** on a track adds it to the time selection or takes it out, even if the tracks aren't next to each other.
- **Ctrl + drag** stretches the selection from its fixed corner.
- Shift + click on track names moves the time selection to those tracks. Clicking a track name dims the time selection, like Live.
- Only the last track you touched gets the highlighted lane.

**Colors**
- Every color in Colors has an **opacity** slider. Double-click it to go back to the skin's.
- Picking a new color over an invisible one no longer stays invisible.
- The selected track's lane now shows in the XUXU and TROOPER3 skins too.
- The grid and background stripes look like Live's in the XUXU and TROOPER3 skins too.
