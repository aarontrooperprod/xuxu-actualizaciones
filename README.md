# XUXU

Aaron's DAW, built for recording.

## Download

Get the one for your computer. You install it once and it updates itself from then on.

### Windows

**[Download XUXU 0.3.31 for Windows](https://github.com/aarontrooperprod/xuxu-actualizaciones/raw/main/XUXU.zip)** (Windows 10 and 11, 64-bit, 4.8 MB)

1. Unzip it into a folder of yours (for example `Documents\XUXU`), not in Program Files.
2. Open `XUXU.exe`. If Windows says "Windows protected your PC", click **More info** and then **Run anyway**.
3. From then on XUXU updates itself: when you open it, it tells you if there's a new version and asks. There's also **Options → Check for Updates…**.

## What's new in 0.3.31

## XUXU 0.3.31 🎛️
**Groups in the mixer, like Live**
- Each group level now moves its tracks' headers down a step, with the group's color running above everything inside it. Groups inside groups are easy to read.

**A tighter mixer**
- Monitor, arm, M and S share one row, and peak and volume sit side by side.
- No more empty gap above the pan: that space goes to the fader.
- The latency bar only shows when a track has latency.
- Empty insert slots only fill the space that's there: a scrollbar only shows on a track that has more plug-ins than fit.
- Group and Master pan are now level with the tracks'.
- Sends show just the bus letter (A, B, C…). The menu shows the letter and the bus name, like "A Reverb".

**Buses**
- New buses start without a tag (they were tagged SFX).
- A bus can no longer be sent to itself, or to a bus that already feeds it.

**Smaller tracks**
- Tracks can go a bit smaller, and at the smallest height a clip is just its name bar, like in Live.
