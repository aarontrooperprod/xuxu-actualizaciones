# XUXU

Aaron's DAW, built for recording.

## Download

Get the one for your computer. You install it once and it updates itself from then on.

### Windows

**[Download XUXU 0.3.29 for Windows](https://github.com/aarontrooperprod/xuxu-actualizaciones/raw/main/XUXU.zip)** (Windows 10 and 11, 64-bit, 4.7 MB)

1. Unzip it into a folder of yours (for example `Documents\XUXU`), not in Program Files.
2. Open `XUXU.exe`. If Windows says "Windows protected your PC", click **More info** and then **Run anyway**.
3. From then on XUXU updates itself: when you open it, it tells you if there's a new version and asks. There's also **Options → Check for Updates…**.

## What's new in 0.3.29

## XUXU 0.3.29 🛠️
**Fixes from Gabriel's list**
- The Compressor and EQ windows no longer change size when a value gets longer or you pick another filter type.
- No more little box around the pan or fader after you click it.
- Buses no longer jump up and down while you drag audio onto a track.
- Clip edges look the same inside a time selection.
- A bus shows up only once in a track's sends.
- Renaming a bus track renames the bus (its sends and outputs follow).
- Plug-in slots are evenly spaced.
- Menus always fit on screen (the Master's menus in automation mode used to go off the bottom).
- Scrolling stays smooth all the way to the top and bottom of the arrangement.
- ↑/↓ start from the track you selected with the mouse, and the view follows the track.
- Closing a plug-in window takes you back to XUXU, not to another program.

**Smaller projects**
- Imported audio is now saved as it came: WAV, AIFF, FLAC, MP3 and OGG keep their own size. An 8 MB MP3 used to become a 70 MB file inside the project; now it stays 8 MB.
- Old Backup copies from before 0.3.27 are big. They go away on their own after you save 10 more times.

**Smoother zoom**
- Ctrl+wheel zoom is much smoother: about 60 frames per second instead of 40 on a big project, and it looks exactly the same.
