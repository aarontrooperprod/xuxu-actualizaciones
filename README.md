# XUXU

Aaron's DAW, built for recording.

## Download

Get the one for your computer. You install it once and it updates itself from then on.

### Windows

**[Download XUXU 0.3.24 for Windows](https://github.com/aarontrooperprod/xuxu-actualizaciones/raw/main/XUXU.zip)** (Windows 10 and 11, 64-bit, 4.7 MB)

1. Unzip it into a folder of yours (for example `Documents\XUXU`), not in Program Files.
2. Open `XUXU.exe`. If Windows says "Windows protected your PC", click **More info** and then **Run anyway**.
3. From then on XUXU updates itself: when you open it, it tells you if there's a new version and asks. There's also **Options → Check for Updates…**.

## What's new in 0.3.24

## XUXU 0.3.24 🚀
**Saving no longer freezes**
- Big projects with Vovious, Melodyne or VocAlign used to go blank for a second on every save, and on every autosave too (once a minute). Now it's instant.
- Autosave waits until you stop playing.
- If XUXU closes unexpectedly, the next time you open it **Recover** comes first, and it tells you which plug-in did it. You can **Recover without** that plug-in (it stays off, with its settings kept).

**Uses all your CPU cores**
- Tracks are processed on several cores at once, like Live and Logic. Heavy plug-in sessions run up to 10× lighter. It sounds exactly the same.
- Preferences → Audio → CPU: **Multicore Support** and **Processing Threads**.

**Strip Silence, like Pro Tools**
- Edit → **Strip Silence…** (Ctrl+Shift+E). What will be removed shows striped on the clips while you move the controls.
- Works on Selected clips, a Track, a Tag (only Vocals, for example) or All. **Auto** finds the threshold for each clip.
- **Listen** plays the result before you cut. One Ctrl+Z undoes it all.

**Faders and pans**
- A click no longer jumps the fader or pan: drag from where it is.
- Click it and type an exact value (−6, 30L…), Enter to set it.

**Also**
- Appearance → Zones & Tracks → Waveform: **Track · White · Black · Custom**.
- Loop lines stay in place when you zoom fast.
- The update popup shows the version and a **What's new** arrow.
