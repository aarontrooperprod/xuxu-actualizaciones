# XUXU

Aaron's DAW, built for recording.

## Download

Get the one for your computer. You install it once and it updates itself from then on.

### Windows

**[Download XUXU 0.3.30 for Windows](https://github.com/aarontrooperprod/xuxu-actualizaciones/raw/main/XUXU.zip)** (Windows 10 and 11, 64-bit, 4.8 MB)

1. Unzip it into a folder of yours (for example `Documents\XUXU`), not in Program Files.
2. Open `XUXU.exe`. If Windows says "Windows protected your PC", click **More info** and then **Run anyway**.
3. From then on XUXU updates itself: when you open it, it tells you if there's a new version and asks. There's also **Options → Check for Updates…**.

## What's new in 0.3.30

## XUXU 0.3.30 🔍
**Big projects open without freezing**
- Opening a big project used to freeze XUXU for several seconds. Now you see "Opening…" with its progress, and XUXU only pauses for a moment at the end, while the plug-ins load (8 s → about 1.5 s on a 47-track project).
- The MicroMeters no longer gets stuck after opening a project.

**Zoom, fixed properly**
- In 0.3.29 waveforms went blurry for a moment on every wheel notch while zooming. That's gone: they always look sharp.
- Zooming is still faster than before (about 50 frames per second instead of 40 on a big project), with nothing looking different.

**Groups are easier to read**
- Tracks inside a group are indented more, so you can see what's inside what, even with groups inside groups.

**New: only the selected track's plug-in windows**
- Under Inserts, next to the "1", there's a new link button. Turn it on and selecting another track closes the plug-in windows of the track you left, like Logic's Link. Off by default.

**New: stop at the end**
- Preferences > Display > Transport > **Stop at End of Last Clip**. With no loop, playback stops when the last clip ends. Off by default (it keeps playing, like Live).
