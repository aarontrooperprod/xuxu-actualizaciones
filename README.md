# XUXU

Aaron's DAW, built for recording.

## Download

Get the one for your computer. You install it once and it updates itself from then on.

### Windows

**[Download XUXU 0.3.13 for Windows](https://github.com/aarontrooperprod/xuxu-actualizaciones/raw/main/XUXU.zip)** (Windows 10 and 11, 64-bit, 4.4 MB)

1. Unzip it into a folder of yours (for example `Documents\XUXU`), not in Program Files.
2. Open `XUXU.exe`. If Windows says "Windows protected your PC", click **More info** and then **Run anyway**.
3. From then on XUXU updates itself: when you open it, it tells you if there's a new version and asks. There's also **Options → Check for Updates…**.

## What's new in 0.3.13

## XUXU 0.3.13 🎛️
**DeEsser, rebuilt and simpler**
- It now looks like Splits: the vocal in blue, the esses in orange.
- **bright / dark** on the left finds the esses. The **S-Max / S-Min** lines on the waveform set how loud an ess can get (drag them).
- **Vocal** and **Esses** faders, each with its own Solo.
- Two optional steps on the side: **Ess EQ** (like Re-Esser: live spectrum, 7 filter types, Freq / Gain / Q per band) and **Compressor** (like the Waves DeEsser).

**Tracks and mixer**
- **Select several tracks and move them together:** volume, pan, mute, solo and arm.
- **Shift+click** M, S or arm to apply it to every track in between. Ctrl+click goes one by one.
- **Type a value:** click a control, type the number and press Enter. Or click the number you see.
- Tracks inside a group no longer show the group's name on top.

**Other**
- The crash log (Documents\XUXU\xuxu.log) is now in English.
