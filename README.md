# XUXU

Aaron's DAW, built for recording.

## Download

Get the one for your computer. You install it once and it updates itself from then on.

### Windows

**[Download XUXU 0.3.20 for Windows](https://github.com/aarontrooperprod/xuxu-actualizaciones/raw/main/XUXU.zip)** (Windows 10 and 11, 64-bit, 4.6 MB)

1. Unzip it into a folder of yours (for example `Documents\XUXU`), not in Program Files.
2. Open `XUXU.exe`. If Windows says "Windows protected your PC", click **More info** and then **Run anyway**.
3. From then on XUXU updates itself: when you open it, it tells you if there's a new version and asks. There's also **Options → Check for Updates…**.

## What's new in 0.3.20

## XUXU 0.3.20 📂
**Importing several audio files**
- Drop several audio files at once and **each one goes on its own track**, all at the same bar.
- Dropped on an audio track: the first one lands there and the rest on the audio tracks below (new tracks are added if there aren't enough).
- Dropped in the empty area: each one gets a new track named after the file.
- Hold **Ctrl** when you let go to put them **all on one track**, one after the other.
- File → Import Audio… with several files also puts each one on its own track.
