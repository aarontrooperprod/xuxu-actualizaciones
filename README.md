# XUXU

Aaron's DAW, built for recording.

## Download

Get the one for your computer. You install it once and it updates itself from then on.

### Windows

**[Download XUXU 0.3.18 for Windows](https://github.com/aarontrooperprod/xuxu-actualizaciones/raw/main/XUXU.zip)** (Windows 10 and 11, 64-bit, 4.6 MB)

1. Unzip it into a folder of yours (for example `Documents\XUXU`), not in Program Files.
2. Open `XUXU.exe`. If Windows says "Windows protected your PC", click **More info** and then **Run anyway**.
3. From then on XUXU updates itself: when you open it, it tells you if there's a new version and asks. There's also **Options → Check for Updates…**.

## What's new in 0.3.18

## XUXU 0.3.18 🔍
**Zoom, waveforms and grid like Ableton Live**
- Zoom in all the way to single samples: real peaks from afar, the actual line through the samples up close, with a dot on each sample.
- The grid lands exactly on its pixel at every zoom: no more ghost lines next to the bar.
- Grid lines are one pixel thin, like Live; bars stand out by being darker. Background stripes alternate by beat, bar, 4 or 16 bars, in Live's tones.
- The bar ruler and the time ruler look like Live's: light ticks and each number next to its ┌ tick.
- Tracks can be made almost as tall as the arrangement.

**Plug-in windows**
- Plug-in windows stay on top of XUXU and no longer add taskbar buttons, so clicking the arrangement doesn't hide Melodyne or Vovious anymore.
- Under Inserts on each channel: **1** = one window per track, the **eye** hides or shows that track's windows (Ctrl+Alt+W) and the **X** closes them. Alt+F12 closes them all.
- XUXU's own plug-ins (EQ, Compressor, MultiMeter…) can have several windows open at once.
- Drag a plug-in onto another track to move it; hold Ctrl to copy it.
- Duplicate plug-ins show up once in the list (Preferences → Plug-Ins → Show Duplicates shows them all).

**Mixer and toolbar**
- Drag the line above the faders to make them shorter or taller; double-click resets.
- The toolbar edit mode (pencil) has a **Size** slider: 100% is the biggest that fits in one row.
- The selected track's buttons can have their own color in Colors.

**Fixes**
- Fade handles stay in place when zoomed in a lot.
- Take lanes show the grid again.
- No gap between the track list and the lanes.
