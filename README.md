# XUXU

Aaron's DAW, built for recording.

## Download

Get the one for your computer. You install it once and it updates itself from then on.

### Windows

**[Download XUXU 0.3.33 for Windows](https://github.com/aarontrooperprod/xuxu-actualizaciones/raw/main/XUXU.zip)** (Windows 10 and 11, 64-bit, 4.8 MB)

1. Unzip it into a folder of yours (for example `Documents\XUXU`), not in Program Files.
2. Open `XUXU.exe`. If Windows says "Windows protected your PC", click **More info** and then **Run anyway**.
3. From then on XUXU updates itself: when you open it, it tells you if there's a new version and asks. There's also **Options → Check for Updates…**.

## What's new in 0.3.33

## XUXU 0.3.33 🎚️
**Sends**
- Each send's level box fills up with its value, like Live, so you can see how much you're sending.
- A send now tops out at 0 dB, like Live (it went to +6). Its automation lane too.
- Double-click a send to reset it to −∞, its default.

**Waveforms** (Preferences → Appearance → Zones & Tracks)
- Track: a Tone slider, lighter to darker, always in each track's own color. Plus Opacity.
- White, Black and Custom have Opacity too.
- A waveform can never end up the same color as its clip: XUXU keeps it visible.

**Small things**
- Appearance is now the last tab in Preferences.
- Alt + mouse wheel over the bar ruler makes every track taller or shorter at once.
